# N SPORTS — Landing Page

Projeto completo (HTML, CSS e JavaScript), pronto para publicar no GitHub Pages e na Vercel.

## Personalização solicitada
- Nome: **N SPORTS**.
- Logo: https://ik.imagekit.io/verlcwgen/Logo_N_Sports_4K_Transparente.png
- **Logo ampliada** para ganhar destaque no desktop e no celular.
- Cabeçalho **branco**, com menu e pesquisa à direita (ícones escuros).
- **Sem Instagram ou WhatsApp no cabeçalho**, nem link de WhatsApp no menu.
- **Único botão de WhatsApp:** flutuante na parte inferior direita, link https://wa.me/5586988567385
- Fundo preto do restante do catálogo, coleções, escudos, cards dos escudos menores (108 px mobile, 124 px tablet e 140 px desktop),
  com logos dentro do círculo e margem para evitar cortes,
  movimento automático dos carrosséis e links dos catálogos preservados da DEDÉ STORE.

Abra `index.html` para visualizar localmente ou publique todos os arquivos na raiz do repositório.
A logo é carregada diretamente do ImageKit; exige conexão à internet, assim como
os banners e escudos que já eram externos. Caso indisponível, exibe o texto N SPORTS.

Para alterar no futuro, edite `configuracao.js`.
